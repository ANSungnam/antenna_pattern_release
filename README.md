# Antenna Pattern releases

## Antenna Pattern Tauri v0.01.00

[Download Windows and Ubuntu packages](https://github.com/ANSungnam/antenna_pattern_release/releases/tag/tauri-v0.01.00)

- Windows desktop: `antenna-pattern-tauri-v0.01.00.exe` or the Windows x64 ZIP. Microsoft Edge WebView2 Runtime is required.
- Ubuntu 24.04 x86_64: the server deployment archive. Installation instructions are included.
- Public web app: https://54.116.163.45/antenna/
- Verify downloads using `SHA256SUMS.txt` attached to the release.

The desktop app and web app read measurement workbooks without Microsoft Excel. OPEN displays the selected sheet in the built-in read-only viewer.

Source code is maintained separately in a private repository. Public assets do not include measurement workbooks or credentials.

[Earlier Windows releases](https://github.com/ANSungnam/antenna_pattern_release/releases) remain available.
